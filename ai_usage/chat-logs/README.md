# Exported AI chat logs

Required by §4.1 of the challenge document: full conversation logs with any AI
agent used during development, exported as plain `.txt` and committed here.

Naming: `YYYY-MM-DD_<topic>.txt`, e.g. `2026-09-08_phase1-ingestion.txt`.

Logs are exported at the end of each working session. Any API key or secret that
appeared in a session is redacted before commit, and the key itself is rotated.
